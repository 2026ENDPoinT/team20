# 교선·전선 관심 태그와 과목 목록

2026-2 활성 강좌 DB에서 이수구분이 전선 또는 교선인 과목을 조회했다. 2021~2026 강좌는 과거 이수내역 대조에 사용하며, 아래 목록은 2026-2 추천 화면용이다. 분반을 과목코드 기준으로 합쳐 전선 24개, 교선 173개를 확인했다. 과목명과 제공된 교양 영역으로 194개를 잠정 분류했고, 주제가 불명확한 3개는 확인 대상으로 남겼다. 강의계획서와 개별 분반 수강 자격은 검토하지 않았다.

## 추천에 사용하는 방법

- 학생은 관심 태그를 여러 개 선택할 수 있다. 과목에도 여러 태그를 붙인다. 예를 들어 데이터마이닝은 AI·데이터와 데이터베이스·데이터 처리에 함께 들어간다.
- 해당 학기의 개설 여부, 이수 여부, 분반 수강 자격을 먼저 확인한다. 요건 및 이수구분에 따른 우선순위를 유지하고, 같은 추천 등급의 전선·교선 후보에서 관심 태그로 순서를 조정한다. 태그가 없는 과목도 후보에 남기고, 관심 주제를 선택하지 않으면 기본 순위를 사용한다.
- 첫 화면에는 전공 관심사와 교양 관심사를 나눠 자주 쓰는 태그를 보여주고, 상세 태그는 전체 목록에서 선택하도록 한다. 태그 ID는 과목코드와 매핑한다. 이름이 같은 전선·교선에는 각각의 코드를 사용한다.
- `(국제)` 표기나 영어 과목명으로 수강 가능 여부를 결정하지 않는다. 분반별 비고·기타 안내 등 수강 자격 근거를 별도로 확인한다.
