# 컴퓨터공학과 학번별 교과 이수요건

[검증된 교과 이수요건](../../sources/graduation_requirements.md)을 기준으로 작성한 2021~2026학번의 조건 데이터다. 각 연도의 JSON은 주간·일반 신입학·단일전공·일반졸업에 적용한다. `applies_to`가 일치하는 파일을 선택한다.

| 필드 | 용도 |
|---|---|
| `requirements` | 학교 공통·학교 교양·공학Ⅱ계열·컴퓨터공학과의 필수조건. 각 배열의 조건을 모두 확인한다. `choose_n`은 같은 조건 안에서 지정 과목코드 중 최소 수를 충족한다. `min_group_credits`에는 해당 과목군의 인정학점을 사용한다. |
| `elective_core_areas` | 교양선택인 4·5영역 목록. 2023학번부터 수록한다. |
| `credit_rules` | 인정학점 제외·상한·중복 인정과 승인된 영어 면제 처리. 과목군의 학점과 전체 인정학점을 계산할 때 해당 규칙을 적용한다. |
| `pending_reviews` | 명시된 사례에서 추가 확인이 필요한 조건. 학점 인정이나 대체 승인에 영향을 주는 경우 확인 필요로 표시한다. |
| `default_credit_summary` | 면제나 예외가 없는 기본 이수 구성의 설명값. `general_total_min: null`은 해당 학번에 별도 교양 총량 기준이 미적용임을 뜻한다. |
| `source_refs`, `sources` | 각 조건의 공식 자료 ID와 원문 위치, 공식 URL. |

조건의 교과목 식별자는 `course_code` 문자열이다. 화면에서는 연결된 공식 분반의 `course_name`을 표시한다. 과목을 추천하는 경우에는 추천 대상 학기의 개설강좌 이름을 사용한다. 조건에 붙은 `title`은 요건의 설명이다.

2021·2022학번 핵심교양의 `course_codes`에는 공학 인증 표기 제한의 적용 여부와 관계없이 사용할 수 있는 후보를 넣었다. 인증 표기가 없는 후보만 이수한 경우 해당 영역은 확인이 필요하다. 2021학번 통합 물리와 분리 교과의 대체 인정도 별도 확인 대상으로 기록한다.

총·전공·교양은 각각의 인정학점을 기준으로 계산한다. 학교 총학점에 전공·교양 인정분이 포함되며, 교양필수와 전공필수 기본 합계는 별도로 더하지 않는다. 공식 분반과 연결됐지만 인정 분류의 근거가 부족한 과목은 학점 계산에서 확인 대기로 표시한다. 체육 상한의 분류에는 수강 시점의 공식 체육영역 근거가 필요하다.
