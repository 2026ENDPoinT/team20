# CPG 추천 알고리즘 설계안

2026-11-13 · 설계 제안 · [JSON 규약](01-json-contracts.md) · [작업 기록](04-decisions-and-work.md)

과목 추천은 학생이 이수할 과목의 우선순위를 정한다. 시간표 설계는 대상 학기에 실제 개설된 분반 중 조건에 맞는 조합을 찾는다. 두 기능은 이수요건과 수강 자격 판정을 공유하고 각각 실행할 수 있다. 과목 저장은 학생이 선택한 항목을 시간표 조건으로 넘기는 선택 경로다.

## 공통 후보 판정

1. 학생의 확인된 이수내역을 학기·전체 강좌코드로 공식 강좌와 연결한다. 학번별 규칙을 적용해 요건을 충족·미충족·확인 필요로 계산한다.
2. 대상 학기 강좌를 공식 과목 ID로 묶고 학과·학년·개별 분반 제한, 선수·동시수강 조건, 이미 이수한 과목의 재수강 허용 여부를 판정한다. 제한은 분반별로 확인한다.
3. 수강할 수 없음이 확인된 분반은 제외한다. 같은 시간표에서 동시수강 조건을 충족할 수 있는 분반은 조건부 후보다. 제한 자료가 없으면 과목 추천에 확인 필요를 표시하고 확정 시간표 후보에서는 제외한다. 검수된 자료가 부족해 조합 가능성을 판단할 수 없으면 `undetermined`를 반환한다.

## 과목 추천 · 규칙에 따른 순위

대상 학기 개설 과목마다 `이 과목을 이수하면 확인된 남은 요건 중 무엇이 달라지는가`를 계산한다. 우선순위는 개정 2 JSON 계약의 기본 순서를 따른다.

| 우선순위 | 기준 | 표시할 이유 예시 |
| --- | --- | --- |
| 1 | 남은 전공필수 | 전공필수 한 조건 충족 |
| 2 | 아직 채우지 못한 핵심교양 영역 | 핵심교양 3영역 충족 |
| 3 | 기초·학문기초교양 | 기초교양 국제화 조건 충족 |
| 4 | 전공선택·일반교양 | 전공 인정학점 6학점 부족 중 3학점 충당 |

4순위에서는 해당 학점 부족량이 큰 범주를 먼저 두며 동률은 전공선택 우선이다. 같은 순위의 교양끼리는 근거 있는 관심 태그를 반영하고, 마지막 동률은 과목 ID로 정렬한다. 과목 한 건에 수강 가능한 분반을 묶어 보여준다. 같은 택1 그룹의 두 과목은 각각 대안으로 추천할 수 있으며, 둘을 함께 이수했을 때 같은 요건을 두 번 충족했다고 계산하지 않는다. 국제교류처의 실용영어의사소통과 고급반도 학번의 국제화 규칙과 분반 자격에 따라 판정한다.

## 시간표 설계 · 제약을 만족하는 조합 탐색

빈 `selections`로 시작하면 대상 학기 개설강좌에서 과목과 분반을 자동 선택한다. 학생이 지정한 필수 과목은 꼭 포함하고, 선호 과목은 가능할 때 우선 포함한다. 첫 구현은 CSV의 교시 구간을 재사용하는 **가지치기 백트래킹**으로 한다. 학기 전체에 대한 탐색 성능은 후보 수와 제한 시간 내 결과를 측정한 뒤 판단한다.

1. 불가 요일·시간, 언어, 확인된 수강 자격을 먼저 검사한다. 과목별로 분반을 묶고 과목당 최대 한 분반을 고른다. 필수 과목을 먼저 탐색하고 필수 과목끼리는 가능한 분반이 적은 순서로 처리한다. 그다음 선호 과목과 확인된 남은 요건을 채우는 과목을 우선 탐색한다.
2. 분반을 추가할 때 교시 충돌과 학점 상한을 검사한다. 남은 과목의 최대 가능 학점을 더해도 희망 최소학점에 도달할 수 없으면 해당 분기를 중단한다. 동시수강 조건은 후보 완성 시 확인한다.
3. 제약을 통과한 후보는 **선호 과목 포함 수 → 새로 충족하는 필수조건 수 → 줄어드는 인정학점 부족량 → 등교일 → 공강** 순으로 비교한다. 학생이 등교일·공강 정렬을 고르면 선택한 기준을 먼저 적용한다. 동일 분반 집합은 한 번만 표시한다. 상위 결과가 분반 한두 개 차이로 반복되면 다른 과목 조합을 별도 후보로 보여주는 방식을 검토한다.
4. 초기에는 기존 API 명세의 2초·100,000개 탐색 노드 한도를 적용한다. 일부 탐색으로 확보한 후보는 표시하고 `truncated`를 반환한다. 검증된 범위를 모두 탐색해도 후보가 없을 때 `no_feasible_plan`을 반환한다. 시간 초과나 누락 자료 때문에 판단할 수 없으면 `undetermined`다. 결과 후보는 전체 제약을 다시 검사한 뒤 반환한다.

부족 학점은 계획 적용 전후의 차이로 계산한다. 총·전공·교양 부족량을 합쳐 같은 인정학점을 여러 번 세지 않는다. 어느 범주를 얼마나 줄였는지는 각각 표시한다. 교시 단위 데이터로는 등교일과 공강 교시 수를 비교할 수 있으며, 공식 시각 대응표를 연결한 뒤 `gap_minutes`를 분 단위로 제공한다.

## 수강신청 실패 대응

확보한 분반을 고정하고 실패 분반을 제외한 뒤 같은 탐색기를 다시 호출한다. 처음에는 실패한 과목의 다른 분반을 찾는다. 다른 과목은 학생이 명시적으로 허용한 경우 탐색한다. 변경이 적은 순서를 기본으로 하고, 확보하지 않은 기존 분반은 유지할수록 우선한다. 결과에는 유지·교체·제외·추가 분반과 예상 이수요건 변화를 보여준다.

## 구현과 검증 순서

1. 대표 학번 한 명의 학생 문서, 확인된 이수내역과 요건, 수강 자격을 직접 검수한 한 학기 분반 묶음으로 시작한다. 과목 추천과 빈 과목 선택 시간표를 각각 검증한다.
2. 저장된 실제 CSV로 분반 교시 파싱과 충돌 검사를 검증한다. 725분반의 교시를 파싱했고, `Database(21001)`와 `게임프로그래밍(31001)`은 목요일에 겹친다. `Database(21001)`와 `실용영어의사소통(11001)`을 고정하고 금요일을 막으면 `프로그래밍입문(2)`의 3분반 중 시간상 `11001`만 남는다. 수강 자격은 별도로 확인한다. [로컬 CSV와 범위](../../seoultech_class/timetable_lab/README.md)
3. 입력과 제약을 다양하게 바꿔 첫 유효 후보까지 걸린 시간, 탐색 완료 비율, 같은 조합의 반복 정도를 측정한다. 전체 학기 자료에서 탐색 한도로 인해 후보 누락이 잦으면 CP-SAT을 비교한다. 분반별 선택 여부를 0/1 변수로 표현하고 분반 중복·충돌·학점 범위를 정수 제약으로 옮길 수 있다. [OR-Tools CP-SAT](https://developers.google.com/optimization/cp/cp_solver)

현재 CSV에는 233개 과목의 725개 분반이 있고, 105개 분반의 비고 또는 기타에 `전용`, `수강대상`, `미래융합대학강좌` 중 하나가 들어 있다. 이 수치는 수강 제한 검수 대상을 찾기 위한 문자열 집계다. CSV의 교시와 비고만으로 수강 자격·선수과목·학점 인정 여부까지 확정할 수 없다.

## 테스트 구현

- [과목 추천 HTML](../../seoultech_class/timetable_lab/course-recommendation.html)과 [시간표 설계 HTML](../../seoultech_class/timetable_lab/schedule-planner.html)은 파일 탐색기에서 직접 열 수 있다. 두 페이지가 [알고리즘 코드](../../seoultech_class/timetable_lab/recommendation-engine.js)와 개설강좌 CSV를 공유한다. HTTP 페이지는 CSV를 읽고, 파일로 연 페이지는 CSV에서 생성한 브라우저용 사본을 읽는다.
- 추천은 2026학번 테스트 규칙에 이수 과목 코드를 대조한다. 미충족 전공필수, 핵심교양, 기초·학문기초교양, 선택 과목 순이다. 선택 과목은 전공·교양의 수동 부족학점과 전공 우선 순서로 비교한다. 같은 순위는 과목명과 코드순으로 정렬한다. 분반 메모의 일부 전용 강좌 문구를 필터링하며 일반·고급 실용영어 자격은 체크박스로 가정한다.
- 시간표는 각 분반이 쓰는 반 교시를 비트 집합으로 나타낸다. 하나씩 선택하면서 겹치는 시간, 최대 학점 초과, 남은 분반으로 최소 학점을 채울 수 없는 분기를 제외한다. 같은 과목은 한 분반만 담고 프로그래밍입문 한·영 대안과 국제화 동일지정은 함께 담지 않는다. 결과는 선호 과목 포함 수, 새로 충족할 요건 수, 전공·교양 부족학점 보완량, 수업 요일, 공강 교시 순으로 비교한다. 선택한 등교일·공강 정렬은 기본 순위보다 먼저 적용한다.
- 2초 또는 100,000노드 한도에서 확인한 과목 조합별로 가장 높은 순위의 분반 조합을 남겨 최대 다섯 개를 보여준다. 같은 과목의 분반만 바꾸려면 실패 대응에서 기존 분반을 제외하고 나머지를 모두 유지한 상태로 대안을 찾는다.
- 이 버전의 부족학점은 입력값을 사용하며 공식 교시의 실제 시각·선수과목·동시수강·개인별 인정·수강 가능 여부는 검증 범위에 포함되지 않는다. 관심 태그, 여러 학번, 다른 과목으로의 실패 대체는 후속 설계다.

검증에서는 실제 CSV에서 과목 미지정 상태로 금요일을 비워 12~15학점 후보 다섯 개를 찾았고, 각 후보의 학점과 교시 충돌을 검사했다. 브라우저에서 `109004` 이수 후 한·영 대안이 빠지는 것과, 프로그래밍입문(2) 실패 분반을 월요일 11002로 바꾸는 것을 확인했다.

### 2학년 실데이터 비교용 샘플

2023-1, 2023-2, 2026-1 사진의 수강 기록을 완료로 가정하고 두 테스트 화면의 기본값으로 설정했다. 첫 수강 학기로 2023학번을 가정하고 요청대로 학년은 2학년, 대상 학기는 2026-2로 고정한다. 사진의 중복 과목은 이력에는 유지하고 과목과 학점 계산에서 한 번만 반영한다. 학교 개설학점의 단순 합계를 사용해 부족학점 초기값을 산출하며 성적표에 기반한 학점 판정은 별도다.

2023학번의 핵심교양 3영역과 S/W 조건을 적용한다. 시간표에서는 자동으로 고르는 같은 핵심교양 영역 과목이 반복되지 않도록 한다. 전공은 공개 교육과정의 2학기 권장 학년을 기준으로 상급 학년 과목을 제외하고, 남은 요건을 비교한 뒤 2학년 권장 전공을 우선한다. 학년 분류는 비교용 추천 정책이며 개별 분반의 수강 제한은 학교 기준을 확인해야 한다. 검증에서 추천 대상 요건으로 핵심교양 1영역과 창의를 확인했다. 기본 12~15학점으로 교시가 겹치지 않는 후보 5개가 나왔고, 알고리즘 필수·금요일 제외 조건에서도 후보 5개가 나왔다.
