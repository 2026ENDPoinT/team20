# 학생 정보·이수 내역 입력 앱

학생 정보와 수강 내역을 입력하고 SQLite에 저장하는 Python·HTML·JavaScript 로컬 앱입니다.

## 실행

프로젝트 루트에서 실행합니다. Python 3.10 이상이 필요합니다.

~~~powershell
python -B -m intake_app.server
~~~

이 컴퓨터에서 기본 python 명령이 Windows 앱 실행 별칭으로 연결된 경우 번들 Python을 사용할 수 있습니다.

~~~powershell
$pythonExe = 'C:\Program Files\WindowsApps\OpenAI.CodexPrimaryRuntime.v26-1110-973-0_26.1110.973.0_x64__3k8sg7r9htsxt\dependencies\python\python.exe'
& $pythonExe -B -m intake_app.server
~~~

브라우저에서 [로컬 앱](http://127.0.0.1:8765)을 엽니다. `--port`와 `--db`로 포트와 학생 저장 경로를 지정할 수 있습니다. 공식 강좌는 기본으로 `db/courses.sqlite3`를 읽고, `--official-db`로 다른 자료를 지정할 수 있습니다. 에브리타임 가져오기는 서버의 Python에서 공개 시간표를 조회합니다. 종료는 터미널에서 Ctrl+C입니다.

## 입력과 저장

- 상단 **내 정보**에서 학생 정보 → 이수 내역 → 확인 및 저장 순으로 이동합니다.
- 변경사항은 자동 저장되며 같은 주소에서 새로고침하거나 다시 열면 불러옵니다. 여러 탭에서 동시에 같은 기록을 바꾸면 저장 충돌을 표시합니다.
- **가져오기**를 누르면 공유 시간표를 공식 개설강좌 DB와 자동 대조합니다. 학기·과목코드·분반번호로 유일하게 연결되고 과목명과 교수명이 모순되지 않는 과목만 표시합니다. 대조되지 않은 건수도 표시합니다.
- 가져온 목록에서 추가할 과목을 선택하고 **과목 추가**를 누르면 기존 수강내역을 교체합니다. **가져온 목록 삭제**는 아직 추가하지 않은 목록을 닫습니다. **전체 삭제**는 저장된 수강내역을 비웁니다.
- 희망학점은 정수 단위입니다. 과거에 저장한 소수 학점은 입력 화면을 열 때 가장 가까운 정수로 표시합니다.

기본 학생 저장 파일은 `intake_app/runtime/student_inputs.sqlite`입니다. 기존 v1 입력도 읽을 수 있으며 다시 저장할 때 v2로 기록합니다. 다른 탭에서 먼저 저장한 내용이 있으면 버전 충돌을 표시합니다. 공유 URL과 원본 시간표 식별자는 학생 문서에 기록하지 않으며, 재수집 비교에는 해시를 사용합니다.

공식 분반 대조는 가져오기와 추천 요청에서 사용합니다. 학생 입력은 기존 API 버전 번호를 사용해 저장 충돌을 방지합니다.

## 과목 추천

추천 분반 목록과 생성된 시간표의 분반 상세에 에브리타임 별점을 표시합니다. 공식 분반 ID와 활성 스냅샷을 기준으로 `db/everytime_ratings.sqlite3`에서 조회하며, `--ratings-db`로 다른 파일을 지정할 수 있습니다. 평가가 0으로 수집된 분반은 `미평가`, 연결된 별점 자료가 없으면 `자료 없음`으로 표시합니다. [별점 XML 가져오기](../db/README.md#에브리타임-별점)

상단 **과목 추천**을 열면 새 탭에서 저장된 학생 정보로 추천을 실행합니다. 대상 학기는 공식 개설강좌 DB에 적재된 최신 정규학기를 사용합니다. 학생 입력은 입학연도와 학년으로 진행합니다. 이수 과정이 지정되지 않은 기록에는 추천 시 컴퓨터공학과 주간 일반 신입학·단일전공 기준을 적용합니다.

- 추천 화면은 **학번별 요건 → 이번에 챙길 전공필수 → 다음 전공필수 → 필수 교양 → 전공선택 → 교양** 순서로 표시합니다. 처음에는 학번별 요건을 펼쳐 두고, 각 항목을 개별로 접거나 한꺼번에 접고 펼칠 수 있습니다.
- 전공필수 대체 과목과 핵심교양 후보는 충족할 요건별로 묶습니다. **다음 전공필수**를 펼치면 이번 학기 개설 여부를 확인할 수 있습니다.
- 전공선택은 [택1 자료](../data/course_alternatives.json)에서 추천 대상 연도의 과목코드를 확인합니다. 이수 완료 또는 대상 학기에 수강 중인 강좌가 공식 DB와 연결되면 그 그룹의 다른 과목도 추천에서 제외합니다. 프로그래밍입문 택1에도 같은 처리를 적용합니다. 두 전공선택 강좌가 모두 후보이면 한 항목에 묶어 각 강좌의 분반을 표시합니다.
- 입학연도 또는 이수연도 교육과정에서 택1 관계가 확인된 전공선택 두 과목을 모두 이수했다면 **학번별 요건**에 확인 사항을 표시하고 해당 학점을 합계에서 보류합니다.
- 전공선택은 현재 학년, 상위 학년, 편성 학년 미확인 순으로 표시합니다. 저학년 과목은 **저학년 전공선택 더 보기**에서 확인할 수 있습니다. 같은 편성 학년 구간에서는 수강제한 확인 상태와 과목명·관심 태그 일치를 반영합니다.
- 전공과 교양 최소학점을 충족하고 총학점이 부족하면 **전공선택**과 **교양**에서 총학점을 채울 과목을 확인할 수 있습니다.

2021~2026학번 컴퓨터공학과 주간 일반 신입학·단일전공을 지원합니다. 전공선택 편성 학년은 2025·2026학년도 공식 편성표를 사용합니다. 확인되지 않은 분반 제한과 인정학점은 화면에 확인이 필요한 상태로 표시합니다.

## 시간표 생성과 과목 바구니

- 과목 추천의 **+**로 과목을 브라우저 바구니에 담습니다. 시간표 생성에서 과목별로 필수 포함 또는 선호를 지정할 수 있습니다. 바구니는 같은 브라우저와 사이트 주소의 탭에서 공유합니다.
- 시간표 생성은 저장한 학생 정보와 최신 정규학기 공식 분반을 읽습니다. 과목 미지정 상태로도 생성합니다. 최소·최대 학점과 제외 요일은 필수 제약입니다. 후보의 분반을 고정해서 다시 생성할 수 있습니다.
- 같은 과목과 적용되는 택1 계열은 하나만 선택합니다. 전체 교시로 충돌을 검사하고 탐색 범위에서 과목 구성이 다른 후보를 최대 15개 표시합니다. 생성하면 조건 입력 자리에 후보 목록이 나오며, 내부 스크롤로 순위를 확인합니다. 1~3위는 색을 구분하고 후보를 선택하면 오른쪽 주간 시간표에 해당 조합을 표시합니다. **조건 수정**으로 입력을 다시 열 수 있습니다.
- 수업 요일은 강의가 배치된 요일입니다. 수업 사이 빈 시간은 같은 날 첫 수업과 마지막 수업 사이에서 비어 있는 교시를 한 주 기준으로 합산합니다.
- 바로 이어지는 수업은 연강으로 집계하며, 후보 목록과 미리보기에 전공·교양 학점 및 연강 횟수를 표시합니다. 수강 제한을 확인하지 못한 분반이 들어 있으면 잠정으로 표시합니다. 교시는 반 교시 단위로 파싱합니다. 정렬 기준과 거리 자료의 적용 범위는 [시간표 생성 설계](../sources/course_planning_design.md#104-첫-시간표-생성의-제약과-정렬)를 참고하세요.
- `POST /api/schedules`는 학생 정보 버전, 학점 범위, 제외 요일, 필수·선호 과목코드, 고정 분반 ID와 정렬 방식을 받습니다. 응답은 대상 학기와 강좌 버전, 후보, 확인 사유, 탐색 상태를 제공합니다.

### 관심 태그 자동 분류

관심 주제는 전공 7개, 교양 13개로 구성합니다. 과학·수학, 환경·기후, 건강·스포츠는 각각 독립 태그입니다. [태그 데이터](../data/course_interest_tags.json)의 과목코드와 과목명이 일치하면 분류를 재사용합니다. 신규 또는 이름이 변경된 전선·교선은 국문명과 영문명으로 해당 그룹 안에서 자동 분류합니다. 일치하는 태그가 없으면 추천 응답의 \`interest_tags\`에 \`other\`를 반환하고 관심 가점은 0으로 계산합니다. 학생은 목록의 태그를 선택하며, 기존에 저장한 태그 이름은 대응하는 고정 태그로 변환합니다.

추천은 기존 그룹별로 표시합니다. 이번에 챙길 전공필수와 필수 교양 중 이번 학기 후보가 있는 그룹에는 초록색 테두리와 **우선 확인**을 표시합니다.
