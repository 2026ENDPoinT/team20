# 과목 추천 QA — 2026-11-14

## 판정

2026-2, 컴퓨터공학과 주간 일반 신입학 단일전공 시연에서 저장 → 공식 분반 대조 → 학번별 요건 평가 → 추천 응답이 동작한다. 실제 수강 가능 여부가 중요한 배포에서는 분반별 자격 근거와 대상 학기 선택을 보완해야 한다.

## 실행 결과

- 에브리타임 가져오기 12개, 학생 입력·추천 16개 자동 테스트를 통과했다.
- 실제 강좌 DB에서 2021~2026 입학연도 6개 × 현재 학년 4개 × 2026년 정규·계절학기 4개로 총 96개 조합을 실행했다. 각 응답에서 중복 과목코드가 없고 후보마다 분반과 추천 이유가 있었다. 이 조합은 빈 이수내역을 사용했다.
- 임시 학생 DB와 실제 강좌 DB를 연결한 로컬 HTTP 서버에서 2023학번 2학년·2026-2의 저장·추천 요청이 성공했다. 활성 강좌 버전 25에서 요건 18개와 후보 228개를 반환했고, 이전 입력 버전 요청은 409를 반환했다.
- 별도 이수내역 예시에서 이수 또는 수강 중으로 확인된 프로그래밍입문과 해당 택1 대체과목이 후보에서 제외됐다.
- HTTP 화면과 API를 확인했다. 브라우저 조작, 전체 학번 요건의 공식 원문 재검증, 실제 수강신청 성공 여부는 이번 검증 범위 밖이다.

## 보완 사항

| 우선순위 | 항목 | 재현과 영향 |

| 높음 | 대상 학기 선택 | 학생 입력에서 2027-1을 예시와 자동완성에 제시한다. 현재 DB에는 해당 학기가 없어 저장 후 추천 API가 400과 자료 없음 메시지를 반환한다. 활성 학기 목록으로 선택지를 제공하고 미공개 학기를 표시한다. |

프로필의 희망 학점은 검증한 과목 추천 후보 순서에 영향을 주지 않는다. 희망 학점은 시간표 조합 조건으로 적용할 수 있다. 기존 화면의 `no_restriction_recorded`는 DB에 제한이 기록되지 않은 상태를 뜻한다.
