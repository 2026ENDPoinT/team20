# 교과 이수요건 DB 검수 메모

기준일: 2026-11-12  
용도: 과목 추천·수강 계획에 반영할 규칙의 검증 상태 관리

검증 근거와 원본 쪽수는 [검증 부록](<verification_appendix.md>), 적용할 기준은 [교과 이수요건 본문](<graduation_requirements.md>)에 정리했다.

## 추가 확인

- **2021 물리 대체:** 통합 물리학및실험을 현행 일반물리학·실험으로 충족시키는 공식 조합과 적용 범위.
- **모듈·동일·대체 관계:** 본문에서 확인한 프로그래밍입문 영문 택1 과목 이외의 모듈 인정 조건. 과목명이 비슷하다는 이유만으로 인정하지 않는다.
- **전공선택 택1 중복 이수:** [전공선택 택1 자료](../data/course_alternatives.json)의 두 과목을 이미 이수했을 때 인정학점과 적용 학번을 확인한다. 앱은 근거가 있는 이수 사례를 표시하고 해당 학점을 확인 전까지 보류한다.
- **2021~2022학번 핵심교양:** 교양대학 표의 정보통신대학 ‘인증’ 과목 택1 제한이 컴퓨터공학과 일반과정 학생에게도 적용되는지 확인한다. [교양대학 핵심교양 변동표](https://liberal.seoultech.ac.kr/curriculum/education)
- **핵심교양 목록:** 학번별 영역별 공식 과목 목록을 DB로 정리하고, 이후 과목의 소급 인정·대체 여부를 확인한다. 2025~2026의 국제정치의이해를 과거 학번에 자동 소급하지 않는다.
- **기초교양 중복 인정:** 2025 원본 PDF 22쪽(인쇄면 16쪽)과 2026 원본에서 인성·국제화 영역의 중복 인정 기준을 확인했다. 2021~2024학번의 적용 범위와 시점은 추가 확인한다.
- **타학과 학점:** 졸업 총학점 인정과 컴퓨터공학과 전공학점 인정을 구분하고, 공동운영·전공인정 등 상한 예외를 확보한다.
- **학생별 적용:** 면제 승인, 재수강·중복 이수, 교육과정 변경 내역을 대조한다.
- **실제 수강 운영:** 개설학기·분반·수업시간, 선수과목, 학년·학과 수강제한, 학기별 수강학점 한도와 예외를 확보한다.

구현 시 데이터 구분은 [개발 설계 메모](<course_planning_design.md>)를 따른다. 확인이 남은 조건은 확정 규칙과 분리해 관리한다.
